# Technical Support Specialist - Career Opportunity

> Join Oversea Staffing Solutions as a Technical Support Agent providing IT and software assistance to global users.

## Position Overview
Diagnose and resolve technical issues for enterprise software, hardware, and network platforms via phone, live chat, and ticketing systems.

## Key Responsibilities
- Troubleshoot Tier 1 and Tier 2 technical inquiries (software bugs, connectivity, account access).
- Guide end-users step-by-step through technical solutions and knowledge base articles.
- Document bug reports and technical feedback for client software development teams.

## Qualifications & Skills
- Strong problem-solving skills and familiarity with IT operating systems, web applications, and hardware.
- Excellent English communication skills (written & verbal).
- Previous technical support or help desk experience is preferred.
